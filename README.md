# University Student Record and Campus Route Management System

## Module
CIT300 - Data Structures and Algorithms

## Project description
A Java console application demonstrating linked lists, stacks,
queues, binary search trees, hashing, and graphs.

## Features
- Student record management
- Service-request processing
- Recent-action tracking
- Sorted student display
- Fast student searching
- Campus route management
- BFS and DFS traversal

1. Open the project in IntelliJ IDEA, Eclipse, or vscode.
2. Ensure all Java files are in the `src` folder.
3. Compile the project.
4. Run `Main.java`.
